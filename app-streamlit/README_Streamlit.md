# 🔫 Projeto Streamlit Desempenho Furia Blast Bounty 2026

Este projeto é um Dashboard interativo desenvolvido com **Streamlit** para monitorar e analisar o desempenho da FURIA durante o torneio BLAST Bounty 2026. A aplicação recebe um upload dos dados em formato csv e mostra o desempenho da equipe de acordo com os dados coletados.
---

## 🖥️ Demonstração da Interface


O dashboard está dividido em três visões:
2. **métricas em cartões:** são ao total de seis cartões com as seguintes métricas Kills,Deaths,ADR,KAST,Swing e Rating3.0 da equipe caso o filtro esteja default ou por jogador e por mapa.
3. **Grafico de Linha** Monitoramento das partidas de cada jogador por dia de acordo com o Swing.
4. **Grafico de Barras** Desempenho de cada jogador de acordo com a médias de Kills realizada.
